# Внутренняя веб-платформа управления медиа-командой университета

Закрытая веб-платформа для координации участников университетского медиацентра (Фотографы, Дизайнеры, Видеографы, Моушн-дизайнеры, SMM, Руководство, Администраторы).

---

## 🛠 Стек технологий
- **Движок & Бэкенд:** JavaScript (Node.js 20+), Express.js.
- **База данных:** SQLite (`media_app.db`) с пулом быстрых асинхронных операций.
- **Фронтенд:** HTML5, шаблонизатор Nunjucks (`templates/`), Tailwind CSS (CDN).
- **Интеграции:** Telegram Bot API (long polling и inline-оценки), Google Drive API v3 & Apps Script Webhook.

---

## 📁 Структура проекта
```
media_team_platform/
├── db.js                   # Инициализация SQLite, модели, запросы и защита админа stepyn
├── auth.js                 # Middleware авторизации и RBAC (уровни 1-4)
├── telegramService.js      # Telegram бот (@ping_sstu_bot): polling, inline-оценки, команды, отправка файлов
├── gdriveService.js        # Интеграция с Google Диском и выгрузка файлов в целевую папку
├── server.js               # Express сервер, роутинг всех эндпоинтов, обработка файлов multer
├── package.json            # Зависимости и скрипты Node.js
├── bot_config.json         # Настройки токена бота и чатов
├── gdrive_config.json      # Настройки целевой папки и вебхуков Google Диска
└── templates/              # HTML шаблоны с Tailwind CSS
    ├── base.html           # Базовый лейаут и меню навигации
    ├── login.html          # Вход по логину и паролю
    ├── register.html       # Регистрация участников с модерацией
    ├── profile.html        # Профиль участника, задачи и сдача работ
    ├── content_plan.html   # Контент-план, фильтры, дедлайны и создание задач
    ├── task_detail.html    # Карточка задачи с дедлайнами и мини-чатом вопросов
    ├── materials.html      # База рабочих материалов по цехам (Фото, Дизайн, Видео и др.)
    ├── management.html     # Панель руководства (оценки 1-10, реестр команды, drawer)
    └── admin_users.html    # Ветка управления профилями (Ур. 4)
```

## 🔐 Корневой администратор системы
- **Логин:** `stepyn`
- **Пароль:** `1111`
- **Уровень доступа:** `4` (Администратор)
- **Статус:** Неприкосновенный системный профиль. В коде установлена многоуровневая защита: этот профиль **нельзя удалить, заблокировать или понизить в уровне доступа ни при каких условиях**.

---

## 👥 Ролевая модель доступа (RBAC)

| Уровень | Роль | Основные права |
|---|---|---|
| **1** | **Участник** | Просмотр профиля, задач и материалов, взятие свободных задач, сдача отчетов, общение в чате задач. |
| **2** | **Глава цеха** | Права ур. 1 + создание задач в своем направлении, перевод задач в работу/на доработку/выполнено. |
| **3** | **Руководство** | Создание задач, смена дедлайнов, загрузка/удаление материалов, доступ к `/management`, проверка и оценивание (1–10). |
| **4** | **Администратор** | Полный доступ + управление профилями (`/admin/users`): одобрение заявок, смена ролей, удаление. |

## 🚀 Запуск проекта (Node.js)

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm start
```
или для разработки с автоперезагрузкой:
```bash
npm run dev
```
- При старте автоматически накатятся миграции схемы БД, создастся и проверится профиль `stepyn` (пароль `1111`, ур. 4), а также активируются 40 тестовых участников (пароль по умолчанию: `1111`).

### 3. Открытие в браузере
Перейдите по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **Регистрация:** пункт "Подать заявку на регистрацию" (`/register`).
- **Модерация:** войдите под `stepyn` (`1111`) и перейдите во вкладку `🛡️ Управление профилями` (`/admin/users`) для подтверждения новых участников.
